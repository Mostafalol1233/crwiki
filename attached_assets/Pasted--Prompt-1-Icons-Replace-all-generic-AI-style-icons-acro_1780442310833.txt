Prompt 3 — Content management: full
Add or improve the following in the admin content editor:
Bilingual content:
Every content item (events, weapons, articles) must have two fields for title and description:

title_en + title_ar
description_en + description_ar

Display language is determined by the user's selected language on the frontend. Default is English.
Rich text / article body:
The article body editor must render clean HTML on the frontend — strip all raw tag strings from display. Use a proper sanitized HTML renderer, not raw innerHTML injection.
Weapon images on homepage:
Each weapon card on the homepage pulls its image from the weapon's record in the database. Make sure the weapon image field in the admin is:

Uploadable (file upload input)
Saved correctly to Supabase storage
Displayed in LatestWeapons on the homepage using the correct public URL

Event images:
Same as weapons — event image must be uploadable in admin, stored in Supabase, and displayed in FeaturedSection using object-fit: cover at full card width.
Hardcoded dark backgrounds:
Search the entire codebase for any hardcoded color values (#0a0a0a, #111, #161410, #0f0f0f, #1a1a1a, black) that are not wrapped in a theme variable. Replace every instance with the appropriate CSS variable so light mode works correctly everywhere.
