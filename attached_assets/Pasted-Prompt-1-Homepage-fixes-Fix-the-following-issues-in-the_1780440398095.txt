Fix the following issues in the homepage components:

Theme consistency: The dark/light mode toggle must affect every single element. No hardcoded dark backgrounds anywhere — all colors must use CSS variables tied to data-theme. When light mode is active, everything turns light — no black sections remaining.

Events section — image display: Increase event card image height to 220px. Use object-fit: cover and object-position: center. The image must fill the card width completely with no letterboxing or whitespace.

Events section — description text: The description field may contain raw HTML tags. Always strip all HTML before displaying — use a utility function:

js
function stripHtml(html) {
  const tmp = document.createElement('div');
  tmp.innerHTML = html;
  return tmp.textContent || tmp.innerText || '';
}
Apply this to every description field before rendering.
